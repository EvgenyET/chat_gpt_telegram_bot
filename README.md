# chat_gpt_telegram_bot

Бот принимает текстовое сообщение в Telegram, отправляет его в OpenAI и возвращает ответ пользователю. В текущей версии предусмотрены проверка Telegram ID, работа только в личном чате и понятные сообщения при ошибках подключения или API.

**Python-портфолио Евгения Толмачева** · Python · pyTelegramBotAPI · Requests · OpenAI API

![Интерфейс chat_gpt_telegram_bot](docs/preview.webp)

## Возможности

- Обрабатывает входящие текстовые сообщения через polling Telegram Bot API.
- Разрешает обращения только указанному пользователю в личном чате.
- Отправляет запрос в OpenAI Responses API и извлекает текст из ответа модели.
- Обрабатывает сетевые ошибки, проблемы авторизации и лимитов; длинный ответ разбивает на сообщения по 2000 символов.

## Как устроен проект

### Настройки и подключение

[`chat_gpt_telegram_bot.py`](chat_gpt_telegram_bot.py)

Токены и разрешённый Telegram ID читаются из переменных окружения. Системный прокси передаётся HTTP-клиенту и библиотеке бота.

### Запрос к модели

[`chat_gpt_telegram_bot.py`](chat_gpt_telegram_bot.py)

generate_response формирует HTTP-запрос с таймаутом, проверяет статус ответа и собирает текстовые части результата.

### Обработчик Telegram

[`chat_gpt_telegram_bot.py`](chat_gpt_telegram_bot.py)

handle_message проверяет отправителя, вызывает модель и отправляет результат частями. Точка входа запускает polling.

## Технологии и их роль

- **pyTelegramBotAPI**: Получение сообщений, регистрация обработчика и отправка ответов.
- **Requests и OpenAI API**: HTTP-запрос к модели, контроль таймаута и разбор JSON-ответа.
- **Переменные окружения**: Передача настроек подключения без хранения секретов в коде.

## С чего начать просмотр кода

Весь сценарий помещается в chat_gpt_telegram_bot.py. Две основные функции, generate_response и handle_message, разделяют запрос к модели и обработку сообщения Telegram.

## Подготовка и запуск

Создайте отдельное окружение и установите исходные зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Задайте OPENAI_API_KEY, TELEGRAM_BOT_TOKEN и TELEGRAM_ALLOWED_USER_ID (числовой ID пользователя, которому бот разрешает отвечать). Для запуска нужны собственный Telegram-бот и доступ к используемой в коде модели/API.

Переменные окружения: `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USER_ID`. Образец находится в [.env.example](.env.example). Сам файл .env автоматически не загружается: исходники читают окружение процесса. Значения нужно передать перед запуском, например в PowerShell:

```powershell
$env:OPENAI_API_KEY = "YOUR_VALUE"
```

После подготовки настроек и необходимых данных основная точка входа:

```powershell
python chat_gpt_telegram_bot.py
```

`requirements.txt` сохранён из проекта. Это снимок окружения, а не гарантия совместимости с новейшей версией Python. Для старых проектов могут потребоваться соответствующая версия Python и настройка системных компонентов.

## Контекст и ограничения

Один из ранних проектов, начатый в 2022 году и представленный в обновлённой версии интеграции. Здесь отрабатываются связка двух API и обработка ошибок. Каждый запрос обрабатывается отдельно: накопление истории диалога и база пользователей в этой версии не реализованы.

Проверены синтаксис Python-файлов и состав публикации. Полный запуск этой версии с внешними сервисами, локальными данными или моделями не выполнялся; команды выше описывают подготовку по исходникам.
